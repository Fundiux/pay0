# PAY0 observation publisher canary

Standalone Node22 service, private Cloud Run/IAM boundary, **not deployed by this source change**. Runtime has no npm dependencies, Firebase Admin, financial imports or service-account keys. Core Sentinel/observer infrastructure are unchanged.

Build from repository root: `node services/pay0-security-observation-publisher/scripts/build.mjs`. The script verifies the reviewed SHA256 of the single pure server helper before compiling its copy. `node services/pay0-security-observation-publisher/scripts/stage-build.mjs` creates an ignored local 12-file context; it does not upload/build/deploy remotely. Docker final image contains only compiled helper and four native runtime modules. Development TypeScript5.9.3 lock entry was copied from the already pinned Sentinel package lock after offline npm metadata was unavailable; subsequent `npm ci --ignore-scripts --offline` succeeded from that lock, followed by build PASS. Runtime dependency count is zero. A clean container build remains a central verification gate.

Service name proposed `pay0-security-canary`, source project fixed `pay-0-system`, region fixed `us-central1`. Runtime SA proposed `pay0-observation-canary@pay-0-system.iam.gserviceaccount.com` with only `logging.logEntries.create` in source project. IAM private invocation must remain enabled; no allUsers/allAuthenticatedUsers binding. Min0/max1/concurrency1,256MiB,5s request timeout. IAM/resource creation is outside this package's scripts. For exact image/revision arguments, `scripts/render-plan.mjs` prints an offline review plan and origin candidate; a revision passed on CLI is not evidence of deployment. Verify it using Cloud Run metadata before modifying the observer allowlist.

Configuration: `PAY0_SOURCE_PROJECT_ID=pay-0-system`, `OBSERVATION_PUBLISHER_MODE=DISABLED` (default), later `CANARY_DRY_RUN`, then `CANARY` only after central review. K_SERVICE/K_CONFIGURATION/K_REVISION must be Cloud Run provided metadata and match the dedicated service. PORT defaults8080. GOOGLE_APPLICATION_CREDENTIALS and FIRESTORE_EMULATOR_HOST fail config. No .env files or secret IDs are used.

GET `/healthz` is process health, not Logging permission proof. POST `/canary` accepts an empty body only, no query or browser Origin. Caller cannot choose root, actor, event, logName or monitored resource. Synthetic scope is `canary-observation-root` / `canary-observation-actor`; event is AUTHORIZATION_DENIED/SERVER_AUTH_DECISION and must be reported as **synthetic**, not an actual authorization incident. Event ID derives from revision, so retries exercise detector deduplication. PublisherId in the receiver comes from its origin mapping (`pay0-observation-canary-v1`), never from request data.

Metadata project/email must match before acquiring the short-lived runtime access token. One3s AbortController covers metadata identity reads, token fetch and Logging write; early completion aborts outstanding work. URLs are literal, redirects disabled, metadata responses bounded and token only used in Authorization. No token/provider error/body logs. Metadata failure, IAM refusal and ambiguous write timeout return fixed503; no automatic retry. Logging acceptance200 is not downstream delivery proof. `CANARY_DRY_RUN` uses the real API dryRun property and produces no routed event. Per-process quotas6attempts/minute and20total, including failed attempts, plus single inflight; restart resets these quotas, so they are not a durable/global source budget. Receiver has its independent durable quotas.

The pure helper is a future server integration port. It is deliberately **not wired into authGuard**. A later adapter must obtain verified uid and freshly authorized profile root server-side, preserve denial and recovery behavior, isolate observation failure and budget latency. Never bridge client security reports or copied request.data to this port. There is no Firestore/policy mutation API.

Tests: `node --test qa/scripts/remediation-observation-publisher.test.mjs`; all I/O is fake except local loopback HTTP. Deployment steps, limitations and primary references: [SENTINEL-PUBLISHER.md](../../docs/remediation/2026-10-09/SENTINEL-PUBLISHER.md).
